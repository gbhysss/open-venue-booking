# OpenVenue v0.2.2 — first public preview / 首次公开预览

OpenVenue is a self-hosted venue booking and approval system for schools, community centers and small organizations. This is an early preview for independent installation and feedback.

## Included

- Public venue directory, availability and anonymous booking requests.
- Private status links and an authenticated administrator approval workflow.
- Server-side filtering/pagination with full-dataset counts.
- Database-enforced conflict protection and approval-time checks for expired slots, paused venues and capacity.
- Next.js 16.4.3, React 19.2.9, PostgreSQL 17 and a committed npm lockfile.
- Docker Compose setup with unique credentials, non-root runtime, readiness checks and recovery after database restart.
- English/Chinese documentation, fictional screenshots, issue forms, contribution guidance and an MIT license.

Application commit `728b33d42bf9b903579c352e162fa5305c240857` passed [Linux CI and Docker Compose verification](https://github.com/gbhysss/open-venue-booking/actions/runs/41266819211). Publication changes add documentation, screenshots and feedback forms; no application behavior changes are bundled with those materials.

## Install

```bash
git clone --branch v0.2.2 https://github.com/gbhysss/open-venue-booking.git
cd open-venue-booking
bash scripts/setup-docker.sh
```

Docker with Compose v2, Git and OpenSSL are required. Choose your own administrator credentials during setup. See [installation](../installation.md) and [existing-deployment upgrades](../container-verification.md).

## Limits

This is a **pre-release**, not an independently audited production certification. There is no hosted public demo. The interface is currently English; applicant email ownership is not verified. Notifications, multi-tenant isolation, QR check-in, attachments and payments are not included. Public deployments need HTTPS, proxy throttling, backups and a privacy/retention policy.

Please file installation or functional issues through [the templates](https://github.com/gbhysss/open-venue-booking/issues/new/choose); report vulnerabilities through [the security policy](../../SECURITY.md). Do not attach secrets or real booking data.
