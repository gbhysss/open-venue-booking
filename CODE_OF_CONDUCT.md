# Code of Conduct

We want OpenVenue to be a welcoming and constructive community.

Please treat everyone with respect. Harassment, discrimination, personal attacks, threats and disclosure of private information are not welcome. Share feedback on ideas and code, not people.

Maintainers may edit or remove content, close discussions or restrict participation when necessary to protect contributors. For concerns, open a private security or community report to the repository maintainers rather than posting sensitive personal information publicly.
